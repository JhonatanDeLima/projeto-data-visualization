# 📊 Visualização de Dados com Python

Repositório com os notebooks desenvolvidos ao longo de um curso de visualização de dados em Python, aplicados sobre uma base real de imigração para o Canadá.

## 🎯 Sobre o projeto
Cada notebook representa uma aula do curso e constrói sobre o conteúdo do anterior — do gráfico mais simples até visualizações interativas.

| Notebook | Conteúdo |
|---|---|
| `projeto_final` | Introdução ao **Matplotlib**: primeiro gráfico, eixos, títulos e rótulos |
                  | Criação de **figuras e subplots** com Matplotlib| Customização avançada: cores, anotações, estilos de grid  |
                  | Introdução ao **Seaborn**: paletas de cores e temas |
                  | Gráficos **interativos com Plotly** e exportação em HTML |

## 🛠️ Tecnologias
- Python
- Pandas
- Matplotlib
- Seaborn
- Plotly

## 📁 Dados
Base de dados pública sobre imigração para o Canadá (`imigrantes_canada.csv`).

## ▶️ Como executar
```bash
pip install pandas matplotlib seaborn plotly
jupyter notebook
```
